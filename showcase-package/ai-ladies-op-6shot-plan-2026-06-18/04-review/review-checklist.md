# Review Checklist Before Burning Seedance

## Project-Level

- [ ] 6 个镜头是否符合 OP 感，而不是普通剧情段落。
- [ ] 是否避免了真实摄影机推轨、滑轨、升降机、3D orbit，改用日漫 OP 的定版、切镜、分层摄影和少量 parallax。
- [ ] 是否接受“先无对白/无音源”的视觉 OP 版本。
- [ ] 是否要把 Shot 4 的三连快切拆成 3 个独立短镜头。
- [ ] 是否要减少 Shot 5 / Shot 6 的多人数量，降低混脸风险。

## Ratio / Duration

- [x] 全部 prompt 标注 `16:9`
- [x] 全部 prompt 标注 `720p`
- [x] 单段时长为 `4-6s`
- [x] 不使用 1080p
- [x] 不并发提交
- [x] prompt 内有独立 `Audio rule: No BGM`

## Reference Discipline

- [x] 角色 identity sheet 只作为身份参考
- [x] 场景图只作为空间/光线/氛围参考
- [x] prompt 中明确禁止字幕、logo、水印、UI、storyboard artifact
- [x] prompt 中明确禁止 smooth real-camera dolly / 3D glide，并写明 TV anime compositing / cut-based OP grammar
- [x] Shot 1-3 为低风险单/双角色镜头
- [ ] Shot 5 / Shot 6 多角色镜头生成前需要人工确认

## Recommended Submission Order

1. Shot 1: ZC学院开场
2. Shot 2: Claude / GPT 对位
3. Shot 3: Gemini / 豆包闯入
4. Shot 4: DeepSeek / MiniMax / Kimi 三连
5. Shot 5: 社团室全员据点
6. Shot 6: 男主被包围的 OP Hook

If Shot 5 or Shot 6 mixes character identities, retry with fewer characters before continuing.
