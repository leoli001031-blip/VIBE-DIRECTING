为什么要做

画质不是唯一差距。真正难的是分镜、节奏和表达。

AIGC 已经能让普通人生成精美画面，但和有影视背景的人相比，差距常常出现在更隐性的地方：镜头如何切、情绪如何推进、观众应该先看见什么。

不是故事板工具 重点不是某一种故事板模式，而是让 Agent 拥有一套“知道怎么拍”的导演 Skills。
不是一键生成 软件会管理素材、分镜、参考约束、视频请求和回流结果，让项目能持续迭代。
不是堆 prompt Prompt 是结果，背后真正有价值的是项目状态、镜头策略和生成合同。

软件参与方式

从一句想法，到一个可复核的视频项目。

统一输入与 Agent 消息区

脚本、修改意见、图片、声音从同一个入口进入。用户不需要先判断素材属于什么工程字段。

参考资产被项目化

角色、场景、道具不是一次性附件，而是能被锁定和复用的项目资产。

故事流与镜头状态

每个镜头都有自己的生成模式、素材状态和视频进度，适合管理多段短片项目。

项目素材

AI 大小姐群像 OP 的角色和场景参考。

这个项目使用一组既有角色设定和场景参考，由 Agent 整理成后续镜头可复用的参考资产。
