# 软件截图说明

这些截图用于展示 Vibe Director 的软件形态和操作链路。PNG 在 `software-ui/`，网页轻量版 JPG 在 `web/`。

## 01-current-entry-viewport

路径：

- `software-ui/01-current-entry-viewport.png`
- `web/01-current-entry-viewport.jpg`

用途：展示统一输入框和 Agent 对话区。

说明：用户可以把脚本、修改意见、图片、声音都放到底部输入框里。软件不要求用户先理解复杂的素材分类，而是让 Agent 去整理项目状态。

## 02-reference-assets

路径：

- `software-ui/02-reference-assets.png`
- `web/02-reference-assets.jpg`

用途：展示角色、场景、道具参考如何进入项目。

说明：参考图不是一次性 prompt 附件，而是项目里的可复用资产。角色、场景和道具可以被锁定，后续镜头继续复用。

## 05-story-flow

路径：

- `software-ui/05-story-flow.png`
- `web/05-story-flow.jpg`

用途：展示故事流和镜头状态。

说明：每个镜头都有自己的状态、生成模式和视频进度。这里可以讲 Vibe Director 不是只生成单条视频，而是在管理一个视频项目。

## 03-video-preview-status

路径：

- `software-ui/03-video-preview-status.png`
- `web/03-video-preview-status.jpg`

用途：展示视频提交、查询和回流状态。

说明：Seedance 视频生成是串行队列，软件会记录提交号、查询次数和下一段状态，避免重复提交。

## 04-export-page

路径：

- `software-ui/04-export-page.png`
- `web/04-export-page.jpg`

用途：展示交付页。

说明：最终页面不只交付视频，还可以整理单段镜头、参考图、prompt 和提交证据，方便做宣传页或项目复盘。

## 建议展示顺序

1. 先放最终 OP 成片。
2. 展示软件入口截图，说明用户从一句话和素材开始。
3. 展示参考资产截图，说明角色和场景如何被项目管理。
4. 展示故事流截图，说明系统在做镜头规划。
5. 展示视频状态截图，说明视频生成和回流不是黑盒。
6. 最后展示导出页和素材包结构。
