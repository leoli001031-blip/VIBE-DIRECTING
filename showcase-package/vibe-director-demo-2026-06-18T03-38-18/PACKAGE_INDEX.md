# Package Index

| 路径 | 内容 | 展示用途 |
|---|---|---|
| `01-input/` | 原始想法和输入说明 | 展示项目从一句话开始 |
| `02-agent-communication/` | Agent 时间线和消息摘要 | 展示它不是静态表单，而是会读项目、判断缺口、等待确认 |
| `03-project-structure/` | 镜头结构、预览计划、项目摘要 | 展示故事被拆成可执行镜头 |
| `04-reference-assets/` | 角色、场景、道具参考图 | 展示 Image2 产出的可复用资产 |
| `05-storyboard-and-prompts/` | Prompt 摘要、完整 Seedance prompt、QA | 展示中间提示词和质量检查 |
| `06-video-generation/` | Seedance 输入清单、提交 receipt、队列状态 | 展示真实提交给视频模型的请求形式 |
| `07-final-output/` | 最终视频或 pending 说明 | 视频回流后放这里 |
| `screenshots/` | 前端流程截图 | 做网页或录屏时的静态素材 |
| `source-receipts/` | Project.vibe 原始快照 | 留作可追溯项目凭证 |
